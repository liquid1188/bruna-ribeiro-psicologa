# Bruna Ribeiro · Psicóloga

Site da psicóloga Bruna Ribeiro Barbosa Matosinhos (CRP 08/34535). Eleventy, editor Sveltia CMS em `/admin`, hospedagem Vercel.

- `npm install && npm start` para rodar localmente
- Textos editáveis em `src/_data/*.json` e `src/reflexoes/*.md`
- `site.json > setupMode: true` mantém o site fora do Google (staging)
- Formulário de contato via Web3Forms: coloque a chave dela em `site.json > web3formsKey`
